# HeiAQua 项目导航

当前维护的两个项目按用途分开：

| 项目 | 类别 | 功能 | 使用入口 |
|---|---|---|---|
| [claude-desktop-zh-complete](https://github.com/HeiAQua/claude-desktop-zh-complete) | 桌面工具 / 中文配置 | Windows Claude 汉化、原生菜单修复、界面精简、Codex 复现流程 | 仓库 README |
| [wordbank](https://github.com/HeiAQua/wordbank) | 学习工具 / 静态网页 | 函数与极限中英术语、分类搜索、自定义词条、本地学习记录 | README 中的本机运行方法 |

## 内容归属

- Claude 汉化、安装与兼容性记录放在 claude-desktop-zh-complete。
- 数学术语、释义与词库页面放在 wordbank。
- 视频企划书、课程作业等独立内容适合新建各自的仓库，避免和词库源码混在一起。
- API 密钥、个人配置、聊天记录和安装包只留本机。
