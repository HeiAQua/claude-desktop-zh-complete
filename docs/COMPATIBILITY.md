# 兼容性与适配

验证基线：Windows 11 x64，Microsoft Store / MSIX Claude Desktop 4.4212.0，前端位于 `resources/ion-dist.asar`。通过当前电脑完成了原生菜单、前端、导航和建议隐藏的界面验证。

这是补丁而非 Claude 官方中文支持承诺。其源码最初来源于固定提交的社区补丁；本仓库准备/应用的自动化会另行执行测试记录。新版本的 JS 分包名可能变化；附加脚本按组件和标签的唯一锚点定位，不依赖文件名，但锚点数量不符仍停止。

当前版本门控：`4.4212.0` / `4.4212.0.0`。其他版本先在副本适配再扩展支持，不存在“适用于任何版本”的开关。

原生菜单的独立问题：前端请求 `zh-CN`，桌面包存在 `zh-Hans.json` 而缺少 `zh-CN.json`，主进程日志会出现 `No catalog for locale 'zh-CN', using 'en-US'`。附加补丁合并当前包的 en-US、zh-Hans 与社区桌面中文资源，新增 zh-CN；并同步 exe 内嵌 ASAR 头哈希。

不修改网络路由、安全开关、系统语言、账号权限或已有用户 config。签名失效可能使 Cowork VM 不可用；不能把“协作”标签翻译成功等同于 Cowork VM 功能测试成功。

更新后：先保留旧备份；识别新安装版本；在新工作目录重新准备。不要对新版本执行旧目录的恢复。
