# 从零到验收

1. 检查：Windows、Python 3.10+、Claude Desktop 版本/安装目录；确认用户已保存工作。
2. 如果 Claude 未安装，指引从官网/微软商店安装；登录由用户本人操作。不从本项目分发可执行文件。
3. CC Switch 可选。若用户需要 DeepSeek，安装其官方版本，在应用中输入用户自己的 API 密钥，选择 Claude Desktop 模型映射。没有密钥不妨碍汉化安装。
4. 克隆本项目，运行单元测试。先用 `Setup.ps1 -PrepareOnly` 生成补丁并检查 manifest 的四个文件及 SHA256。
5. 只有版本、资源结构、补丁锚点和备份校验全部通过才应用；用户处理 UAC。应用后再次核对文件哈希，保留 jobs 目录。
6. 启动 Claude，左下角账户 → Language → zh-CN。需要时完全退出托盘再启动。
7. 验收并记录：
   - 主界面“新建、自定义、更多、项目或文件夹”为中文。
   - 左上角“协作 / 编程”；设置分类为中文。
   - 左上角主菜单“文件、编辑、视图、跳转、帮助”；逐个检查子菜单：新建会话、打开文件、撤销/重做、命令面板、全屏、后退/前进、搜索。
   - 默认没有“给你的建议”和其三张卡片；保留模式除外。
   - 可选模型菜单：V4.1 Flash 和 V4 Pro，各保留普通/1M，当前选择按用户偏好。菜单显示并不证明 API 请求成功。
8. 失败时：确认同版本，再用 `Apply.ps1 -Restore`；不能删除凭据、会话、整个缓存或复制别人的 config 来修复。

推荐交给 Codex 的目标范围：只更改中文显示和本项目明确列出的菜单整理。服务商账号、模型计费、全局系统设置、Windows 语言、权限策略不属于汉化范围。

恢复后切换英文属于应用语言设置；删除新建资源不删除任何聊天记录。备份可能包含原始程序及本地模型连接配置，不要上传 GitHub。
